# Evaluation Results and Visualizations

This directory stores evaluation metrics, loss/accuracy curves, and confusion matrix plots generated during model training and evaluation:
- `feature_extraction_history.json`: Training and validation loss/accuracy history for the feature extraction stage.
- `finetuning_history.json`: Training and validation history for the fine-tuning stage.
- `feature_extraction_curves.png`: Training/validation curves for feature extraction.
- `finetuning_curves.png`: Training/validation curves for fine-tuning.
- `feature_extraction_metrics.json`: Classification metrics (Accuracy, Precision, Recall, F1, ROC-AUC) on test set.
- `finetuning_metrics.json`: Classification metrics on test set for fine-tuned model.
- `confusion_matrix_feature_extraction.png`: Confusion matrix visualization for feature extraction.
- `confusion_matrix_finetuning.png`: Confusion matrix visualization for fine-tuning.
- `model_comparison.csv`: Tabular comparison of both models across metrics.
- `FINAL_VERIFICATION_REPORT.md`: Comprehensive automated verification report of the entire system.
